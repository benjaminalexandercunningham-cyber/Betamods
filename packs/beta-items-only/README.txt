BETA 1.7.3 ITEMS ONLY v1.0

Behavior pack for Minecraft Bedrock 1.26.50 or newer. Activate under World Settings > Behavior Packs. Stable Script API (@minecraft/server 2.10.0); no experiments needed. Use it INSTEAD OF Beta Inventory Enforcer and Classic Ore Drops & Oak Planks: it covers both. It works alongside Beta Entity Enforcer and the block/item texture filter.

Only the 220 blocks and items in allowlist.json (the Beta 1.7.3 set, under their modern identifiers) can be obtained:
- Dropped items that are not on the list are removed as they appear, so breaking a post-Beta block drops nothing.
- Every player's inventory, armor, offhand and cursor is swept about once a second, in every game mode.
- Vanilla recipes for other items are disabled, and recipes that changed since Beta are put back (golden apple from gold blocks, fences from sticks, one sign or door per craft, and so on).
- Chest, fishing and mob loot no longer contains other items. Beta mobs drop what they dropped in Beta.
- Mobs that did not exist in Beta no longer spawn naturally.
- Iron and gold ore drop the ore block again (raw iron and raw gold are swapped for it).

Known limits: recipes built into the game cannot be changed, so classic slabs still yield 6 and beds can be crafted in any colour. Mobs placed by structures and spawners still appear. Items already inside chests are only removed once a player picks them up. See docs/BETA_ITEMS_ONLY_REPORT.md in the repository for the full list.

The files under recipes/, loot_tables/ and spawn_rules/, and scripts/allowlist.js, are generated by tools/beta_items/generate.py. Edit allowlist.json or tools/beta_items/rules.py and regenerate instead of editing them by hand.

Structural checks, an independent re-check of every recipe and loot table against the allowlist, and a simulated run of the script passed. NOT tested inside a running Bedrock client.
