BETA BLOCK FILTER

Import the .mcpack in Minecraft Bedrock. Activate under World Settings > Resource Packs, above other texture packs. No behavior pack or experiments needed.

Uses the supplied Beta chart as the block keep list. Items shown in the supplied chart are preserved; other item icons and direct item texture files are blanked. Mixed tool/armor arrays preserve the five chart materials and blank copper/netherite variants. Only the oak boat, four original buckets, sixteen original dye ingredients, red bed, standard filled map and music discs 13/cat are kept. Modern equipment may still render through separate attachable models or worn armor textures. Oak planks/building pieces are kept; spruce and birch logs, leaves and saplings are kept. Other wood building pieces are blanked. All wool colors are kept. Red beds are kept. Roses use the current poppy texture. Removed legacy blocks such as locked chests cannot be restored by this pack.

This is a TEXTURE REMOVAL pack, not a guaranteed invisibility pack. All catalogued non-kept block definitions point to transparent pixels, with separate modern placeable-item icon overrides and special-renderer textures. Opaque vanilla block materials may ignore alpha and render black/solid; block collision, shadows, lighting, occlusion, names and inventory entries are unchanged. Some engine-controlled renderers may still be visible. Shared shulker textures also hide shulker mobs. Newly added game blocks beyond the bundled catalogue need an update.

Validated archive, JSON, texture files and keep-list mappings. Not tested inside a running Bedrock client.

VERSION 1.2 FIXES
Overrides both placed textures and carried_textures, plus atlas aliases and direct texture files. Includes six-sided wood, mangrove leaves, kelp blocks, coral, heads, beacon/beam, decorated pots/patterns, vines, tall flowers, sculk, shield models, walls, giant mushrooms and shelf mushrooms. Copper golem models and its statue textures are blanked. Ordinary mobs, original logs and small mushrooms are retained. Complete invisibility of opaque vanilla blocks remains engine-dependent. Install this version above other packs and disable the older versions. No running Bedrock client was available for visual testing.
