# Beta 1.7.3-inspired Bedrock Collection — curated pack release

This collection brings together the latest versions from this project for modern Bedrock.

Included:

- Corrected v1.2 block/item texture filter with snowy grass restored.
- Inventory enforcer v1.1, including the fix that blocks oak and petrified oak slabs.
- Entity enforcer v1.1: removes newer entities and baby mobs, suppresses their normal death effects/drops and removes XP orbs.
- Classic ore and oak plank rules v1.0: normal iron/gold ore drops ore blocks when correctly mined; plank recipes output oak.
- Optional permafrost v2.0: uses custom snow/ice blocks to prevent melting without changing random tick speed.

Use only these selected versions; disable their older counterparts. Enable companion resource packs for the entity and optional permafrost add-ons. See README.md for downloads, resource-pack priority and installation.

Target: Bedrock 1.21.90+, stable Script API 2.0.0. Structural and simulated checks were performed; no live Bedrock gameplay testing was available.

Permafrost is optional because it changes block identifiers and some vanilla interactions. Keep it installed until converted blocks are reverted. Its scanner cannot protect native snow/ice before discovering it.
